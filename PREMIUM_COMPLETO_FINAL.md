## 🤖 SISTEMA MULTI-AGENTE CRIADO

### 1. Instagram Analyzer Agent 🎨
**Arquivo:** `agents/instagram_analyzer.py`

**Função:**
- Analisa identidade visual da marca
- Extrai paleta de cores
- Define tipografia
- Identifica valores da marca
- Determina target audience
- Define tom de voz

**Output:** `brand_identity.json`

### 2. Image Curator Agent 📸
**Arquivo:** `agents/image_curator.py`

**Função:**
- Analisa todas as 180 fotos
- Detecta duplicados (perceptual hash)
- Identifica baixa qualidade (resolução)
- Verifica rotações erradas (aspect ratio)
- Agrupa fotos do mesmo produto
- Gera recomendações de curadoria

**Output:** `image_curation_report.json`

### 3. Premium Site Builder Agent 🚀
**Arquivo:** `agents/premium_site_builder.py`

**Função:**
- Gera CSS customizado com identidade da marca
- Cria homepage premium
- Aplica tipografia profissional
- Configura cores em todo site
- Adiciona trust badges
- Setup de newsletter
- Cria seções com storytelling

**Output:** 
- `premium_custom.css`
- `apply_premium_design.php`
