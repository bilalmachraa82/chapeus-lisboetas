### 🔴 FASE 1: FOUNDATION (2 horas) - **CRITICAL**

**Objetivo:** Core development workflow + Security fixes

#### Instalar:
1. **Playwright MCP** (browser testing)
   ```bash
   npm install -g playwright-mcp @playwright/test
   npx playwright install chromium firefox webkit
   ```

2. **WordPress MCP Adapter** (Automattic oficial!)
   ```bash
   # Via Composer (dentro do container)
   docker exec chapeus_wordpress composer require wordpress/mcp-adapter

   # Ou via WordPress plugin
   # Download: https://github.com/WordPress/mcp-adapter/releases
   ```

3. **GitHub MCP** (oficial, managed endpoint)
   ```json
   {
     "github-managed": {
       "command": "curl",
       "args": ["https://api.githubcopilot.com/mcp/"],
       "auth": "oauth"
     }
   }
   ```

4. **Supabase MCP** (database powerhouse)
   ```bash
   npm install -g @supabase/mcp-server
   ```

5. **Security Fix:** MySQL password
   ```bash
   # Create .env.mcp
   cat > .env.mcp <<'EOF'
   MYSQL_PASSWORD=e$4rU9h8
   MYSQL_USER=lisboetas
   MYSQL_DATABASE=lisboetas_web
   SUPABASE_PROJECT_REF=your_project
   SUPABASE_ACCESS_TOKEN=your_token
   GITHUB_TOKEN=your_github_token
   EOF

   echo ".env.mcp" >> .gitignore
   ```

**Resultado Esperado:**
- ✅ Browser testing automated
- ✅ WordPress operations via AI
- ✅ GitHub automation ready
- ✅ Database ops (Supabase + MySQL)
- ✅ Zero hardcoded passwords

**Time:** 2h
