================================================================================
PROBLEMA IDENTIFICADO
================================================================================

SINTOMA:
- As imagens dos produtos mostram apenas a parte SUPERIOR da foto
- Ao fazer zoom, vê-se apenas o topo em vez da imagem completa
- As imagens parecem "cortadas" ou deslocadas para cima

EXEMPLO VISUAL (homepage_full.png):
- Boina Lã Tweed Patchwork → Mostra só o topo da cabeça
- Boina Newsboy Xadrez → Mostra só a parte superior
- Outros produtos → Mesmo problema

================================================================================
CAUSA RAIZ
================================================================================

PROBLEMA TÉCNICO:
1. CSS usa "object-fit: cover" SEM "object-position: center"
2. Container tem "overflow: hidden" com altura fixa de 500px
3. Thumbnails não estão centralizados verticalmente

ARQUIVOS AFETADOS:
- /wp-content/themes/theretailer/css/styles.css (linhas 5125, 5330, 5370)

CÓDIGO PROBLEMÁTICO:
```css
.woocommerce ul.products li.product .image_container img {
  width: 100%;
  /* FALTA: object-position: center center; */
}

.image_container {
  overflow: hidden;  /* ← Esconde partes da imagem */
}
```

DADOS TÉCNICOS (do visual_debug_report.json):
- objectFit: "cover"
- parentOverflow: "hidden"
- displayHeight: 500px
- naturalHeight: 255px ou 500px (varia)
- boxImageHeight: 500px (fixo)

================================================================================
SOLUÇÃO IMPLEMENTADA
================================================================================

TIPO: CSS Fix (rápido e reversível)

AÇÃO: Adicionar CSS ao child theme para forçar centralização

CSS A ADICIONAR:
```css
.woocommerce ul.products li.product img.attachment-woocommerce_thumbnail,
.product-small .box-image img,
ul.products li.product .image_container img {
  object-fit: cover !important;
  object-position: center center !important;
}
```

IMPACTO: Imediato após aplicar
